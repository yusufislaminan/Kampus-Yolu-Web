🔧 Kampüs Yolu - Veritabanı Düzeltme Aracı

❌ Hata: Field 'location' doesn't have a default value
Sebep: Veritabanındaki users tablosunun location sütunu henüz düzeltilmemiş.

✅ Çözüm

⚠️ Önemli: Aşağıdaki SQL komutlarını WampServer'da çalıştırmanız gerekiyor.

1️⃣ Yöntem 1: WampServer SQL Admin ile

1. WampServer simgesi > MySQL > phpMyAdmin'i tıkla
2. Sol tarafta "kampus_yolu" veritabanını seç
3. Üstte "SQL" sekmesini tıkla
4. Aşağıdaki kodu yapıştır ve çalıştır:

ALTER TABLE users MODIFY COLUMN location POINT SRID 4326 DEFAULT NULL;

2️⃣ Yöntem 2: Backend API ile (Otomatik)

3️⃣ Yöntem 3: Komut Satırında

Windows PowerShell'de aşağıdaki komutu çalıştır:

mysql -h localhost -u root -p kampus_yolu -e "ALTER TABLE users MODIFY COLUMN location POINT SRID 4326 DEFAULT NULL;"

📋 Sonra Yapılacaklar

  1. Veritabanı düzeltildikten sonra sayfayı yenile (F5)
  2. Kayıt formuna dön ve tekrar dene
